# Homebrew tap for Broza

[Broza](https://github.com/borlafu/broza) is a safe disk cleanup CLI for macOS: dry-run first,
reversible quarantine, honest APFS numbers. Apple Silicon only.

```bash
brew install borlafu/broza/broza
```

The formula in `Formula/broza.rb` is written by the Broza release workflow (cargo-dist) on every
tagged release. Do not edit it by hand; open issues in the main repository.
